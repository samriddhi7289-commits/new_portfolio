# Samriddhi Bansal — Portfolio

A responsive, product-oriented personal portfolio built with plain HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in a browser, or use a local static server (for example, VS Code Live Server).

## Included
- Responsive desktop/mobile navigation
- Accessible light/dark theme toggle with saved preference
- Product-oriented hero and project storytelling
- Separate hard-skill indicators and soft-skill descriptions
- Project repository links, experience, education, and contact sections
- Reduced-motion support and scroll reveal effects

## Before publishing
- Add a real résumé file if you want a résumé download button; the current version links to email/contact instead to avoid a broken download.
- Add project screenshots, validated outcomes, and case-study details as available.
- Review the indicative skill bars and change them to levels you can comfortably explain in an interview.
- Verify every role date and profile link. Graduation year and LinkedIn impressions are intentionally omitted from the homepage.

The decorative project graphics are built in CSS and are not screenshots of the live projects.
